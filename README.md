# 🚀 21-Day Backend Engineering Challenge

## 📌 Overview
This repository documents my structured **21-Day Backend Engineering Challenge**, focused on mastering JavaScript fundamentals, backend system design, authentication, and production-level security practices.  

The goal was to move beyond basic CRUD applications and architect secure, scalable backend systems suitable for real-world deployment.

---

## 🎯 Challenge Objectives
- Strengthen core JavaScript fundamentals  
- Master asynchronous programming concepts  
- Build REST APIs using Node.js & Express  
- Integrate MongoDB with structured schema design  
- Implement JWT-based authentication  
- Apply role-based authorization  
- Follow clean MVC architecture  
- Implement production-level security practices  

---

## 📅 21-Day Learning Breakdown

### 🟢 Phase 1 – JavaScript Mastery (Days 1–10)
**Topics Covered:**  
Variables & Scope · Functions · Objects & Arrays · ES6+ Features · Closures · Execution Context · Event Loop · Promises · Async/Await · Hoisting · `this` keyword  

**Outcome:**  
Deep understanding of JavaScript execution and asynchronous behavior.

---

### 🟡 Phase 2 – Backend Development (Days 11–16)
**Topics Covered:**  
Node.js fundamentals · Express.js framework · REST API design · Middleware architecture · MongoDB integration · Mongoose schema modeling · CRUD operations  

**Outcome:**  
Built structured backend APIs connected to a database.

---

### 🔵 Phase 3 – Authentication & Production Security (Days 17–21)
**Topics Covered:**  
User registration & login · Password hashing (bcrypt) · JWT token generation & verification · Role-based authorization · MVC architecture · Service layer separation · Centralized error handling · Helmet middleware · Rate limiting · Environment variable configuration  

**Outcome:**  
Developed a secure, scalable backend system with production-ready structure.
